# Hero · 渡灯录

一款持续开发中的原创中文单机武侠 RPG，使用 **Godot 4.6**。离线运行、无账号、无服务器依赖，进度保存在本机。

当前源码版本为0.0.8，内容包括「青苇渡·渡口失灯」开篇、「废闸疑云」分支行纪，第三地图霜桥驿的第二章「印下有声」，以及第四地图雾竹坡的第三章「听雨辨令」，**不是已达到商业游戏体量的成品**。世界、故事、人物、界面、程序绘制地图与音乐均为本项目原创；背景与四位主要人物头像为独立生成素材。仅借鉴武侠 RPG 的一般玩法类型，没有复制《烟雨江湖》的文本、地图或素材。

## 运行

1. 安装 Godot 4.6.x（已在 4.6.3 验证）
2. 用 Godot 项目管理器导入本目录的 `project.godot`
3. 按 F6/F5 前请确保打开 `scenes/main.tscn`；**F5 运行整个项目**
4. 在「渡灯录」首页选择「踏入江湖」；已有本地存档时可选「续写前缘」

命令行：

```sh
godot --path .
```

Godot 源码工程可以直接运行；Linux 独立发行程序也已在云桌面启动验证。三个桌面目标的导出预设、官方模板校验和构建流程见 `EXPORTS.md`；最新验证范围见 `PROGRESS.md`。未在真实 Windows/macOS 硬件做兼容性验收。

## 可玩的内容

- 1600×1050 原创青苇渡村落、碰撞、镜头跟随、河岸、双栈桥与动态草木/灯火
- 守灯人陆伯、药师沈青、河帮执事蒲横及采集、告示、古碑交互
- 完整任务链：接取委托 → 采草 → 送药取证 → 渡口交锋 → 证据归属抉择 → 门派荐帖
- 回合战斗：普攻蓄气、绝招真气消耗/冷却、守势、药品、敌人意图提示、撤退及败北恢复
- 沈青与唐栖两位可切换同行人，探索中跟随；沈青稳定助攻/减伤，唐栖拆招回气/重击防护
- 唐栖原创个人支线「尺上旧痕」：修桥与霜桥结局后，跨地区找回工册，选择传艺或留存，再邀请同行
- 第四张雾竹坡地图、三处雨痕调查、较量/修亭/公示原账三种通行方式、三阶段守令使与双结局
- 第三张霜桥驿地图、双线索三印机关、封仓首领、公开原账/保护证人结局；修桥会实际打通近路
- 第二张废闸地图、救人/追账顺序分支、证言与账页收集、巡哨和附带破绽状态的首领
- 修为升级、铜钱、回春散购买/消耗、青钢剑购买/装备、三种门派被动加成
- 任务节点自动存档、三份独立手动手记、上一份原子备份、覆盖与读取确认、坏档恢复与安全坐标修复
- B 工艺：四种材料买卖、精锻青钢剑/轻纱内甲/回春散配方；装备不重复叠加，买卖无套利
- 南庭导师岑远：三派不同的实战验艺条件，完成后可暂缓领取，回访晋升内门并获得一次性修行奖励
- 每派三种专属主动武学：入门招式加两门内门藏页；2/3考绩研习、已完成事件一次性复命，学习与装备分离
- 卸劲削弱接下来两次来击；蓄锋将额外伤害留给下一次平击，状态值直接显示于战斗界面
- 武学熟练度阶位，可在 K 武学界面战前切换，最多四门已学招式加返回按钮
- M 舆图显示实际区域、当前位置与任务目标
- 原创合成拨弦音乐、音效、独立生成的水墨渡口标题背景
- 无名客、沈青、唐栖与秦禾的原创头像；对话头像只占标题区，不遮挡正文或选项

## 开篇路线（含轻微剧透）

1. 向前走，找陆伯（中央 520,440）
2. 沿北路向东，采青穗草（东北 1260,350）
3. 返回沈青药铺（西北 330,330）交药
4. 再和沈青交谈可邀其同行
5. 到东南旧渡口（1260,740）挑战蒲横
6. 回陆伯处交证据，选择「秉公」或「守望」及一个修行方向
7. 章节结束后可切磋、购买装备、调整阵型
8. 村东古道（1480,560）通往废闸，任选调查顺序，集齐两份线索后挑战闸首
9. 废闸东北（1450,250）进入霜桥驿，调查纪小砚和旧桥碑文，按线索解开印台
10. 击败韩砚后回温行舟处选择原账归处；采集木料可帮唐栖修通南桥
11. 霜桥东北古道通往雾竹坡：读雨尺与石盂 → 取得巡哨许可 → 拓叠石刻度 → 在守令使回息窗口出招 → 回秦禾处决定先疏水或先警船

无名碑（900,820）与药铺均可免费恢复；不要求磨钱或付费。战败不删除任务和物品。

## 存档

Godot `user://hero_save.json`，新存档为版本6 JSON，仍可读取版本1至5。先写临时文件再替换。无云同步。不要分享个人存档，除非需要排错。当前版本兼容原始字段完整的旧存档，新字段具有默认值。v0.0.6及更早版本会拒绝读取版本6存档，避免静默丢失新系统进度；回退游戏版本前请备份存档，不要把这种拒绝误当作文件损坏。

## 结构

- `scripts/main.gd`：界面、剧情与流程
- `scripts/game_state.gd`：可独立测试的存档、成长与战斗规则
- `scripts/world.gd`：原创场景绘制、探索和碰撞
- `scripts/battle_art.gd`：战斗场景和角色表现
- `scripts/martial_catalog.gd`：武学数据定义
- `scripts/map_chart.gd`：两区域的只读地图概览
- `scripts/frostbridge_region.gd`、`frostbridge_story.gd`、`chapter_rules.gd`：霜桥地图、独立剧情控制与任务规则
- `scripts/item_catalog.gd`、`economy_rules.gd`、`workshop_ui.gd`：材料/配方数据、原子交易和工艺界面
- `assets/generated/`：生成背景与来源说明
- `assets/fonts/`：Noto Sans SC，许可证随附
- `tests/`：逻辑及跨场景回归测试
