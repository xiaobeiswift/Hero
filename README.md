# Hero · 渡灯录

一款持续开发中的原创中文单机武侠 RPG，使用 **Godot 4.6**。桌面包可离线运行，无账号和游戏后端；网页版从网站加载静态资源，进度保存在当前浏览器。

当前源码版本为0.0.20（含鹤汀完章后的可选余事），内容包括「青苇渡·渡口失灯」开篇、「废闸疑云」分支行纪，第三地图霜桥驿的第二章「印下有声」，第四地图雾竹坡的第三章「听雨辨令」，以及第五地图鹤汀埠的第四章「一秤两岸」，**不是已达到商业游戏体量的成品**。世界、故事、人物、界面与音乐均为本项目原创；环境、头像及探索主角包含独立生成并由本项目加工集成的素材。采用通用的武侠 RPG 玩法类型，故事、地图与角色独立设计。

最新完整桌面包：[v0.0.18](https://github.com/xiaobeiswift/Hero/releases/tag/v0.0.18)，提供Linux、Windows和macOS完整下载。新增第五地区鹤汀埠「一秤两岸」：实体粮车、双向浮桥、三批交付、可改分粮草案与两种安排；绘制港务器物、按实际碰撞计算的推车舆图及状态交互提示一并包含。三个精确PCK各通过1111项检查；Linux实际程序验证了开场、港口保存故障恢复、重启、推车过桥和一批粮食交付。Windows/macOS尚无原生验收，具体范围与图像见发行页报告。

**源码与Web测试版先行内容（v0.0.18完整下载尚未包含）：** 青苇渡练武堂南侧的两具木人可按E进入可选演武；点击木人或上方牌签、Tab换目标，1–5出招。执棍木人轮换轻/重击，架盾木人保护同伴，击倒后自动转向尚存目标。使用当前武学/同行的独立演练状态，不消耗真实气血、药品或真气，不发放奖励/熟练；Esc可随时返回。

**0.0.20源码新增：** 鹤汀埠完成「一秤两岸」后，可在东岸找施衡接下「复签不撤」。这场可选实战使用当前气血、真气和回春散；截签刀客进攻，架刀护手替他减伤，点击对手或牌签、Tab换目标。站位表现既有并肩/护后，护手居前、刀客在后；主角贴近已选目标命中后回位，名称与气血跟随实际演出。开篇蒲横及其后续切磋也已适配同一站位舞台，其他对手仍用旧表现；四人绘制招式区、各自资源与行动阶段已在Web0.0.20上线。先保存再开战，首次胜利得到80修为与40文，核签只补全记录；败退送回西岸休整，最多遗落8文，粥棚仍可免费调息。两种分粮结局不变。Web0.0.20 · Web1已包含此项；桌面0.0.18尚未包含。

**四人队伍已上线：** 开篇问剑、蒲横切磋与「复签不撤」已接入主角加三名同伴的独立行动界面。已招募的沈青、唐栖、秦禾各有气血、真气、招式与本轮行动；沈青主动治疗，唐栖卸劲，秦禾为指定队友提供下一击护势。行囊第五项打开四槽同行册，入队/候补不回血，空位不自动补人。秦禾须在雾竹坡任一结局后完成「尺绳有托」并亲口邀请；其他既有遭遇仍在逐步适配，暂使用原来的同行支援。当前网站0.0.20 · Web1已包含此项。

**仍使用旧v0.0.16时：** [v0.0.16.1](https://github.com/xiaobeiswift/Hero/releases/tag/v0.0.16.1)是原Windows/Linux的PCK替换修复，须备份并核对原摘要后按包内说明安装，不含引擎或新功能；macOS没有直接替换包。旧v0.0.16未修复程序在探索保存失败后直接点X/Alt+F4可能丢失本次未存进度，请使用 **Esc → 暂别江湖 → 保存并离开**，失败时留在游戏重试。v0.0.17及之后的完整版本均已包含修复，无需再叠加旧补丁。

v0.0.18完整下载已包含鹤汀埠。它写入存档格式10，可读取旧1–9版；旧v0.0.17不能读取新格式。升级前请保留自己的旧自动存档、三份手记及备份，以便回退。

## 源码工程运行

1. 安装 Godot 4.6.x（已在 4.6.3 验证）
2. 用 Godot 项目管理器导入本目录的 `project.godot`
3. 按 F6/F5 前请确保打开 `scenes/main.tscn`；**F5 运行整个项目**
4. 在「渡灯录」首页选择「踏入江湖」；已有本地存档时可选「续写前缘」

命令行：

```sh
godot --path .
```

Godot 源码工程可以直接运行；Linux 独立发行程序也已在云桌面启动验证。三个桌面目标的导出预设、官方模板校验和构建流程见 `EXPORTS.md`；最新验证范围见 `PROGRESS.md`。未在真实 Windows/macOS 硬件做兼容性验收。

## 开篇路线（含轻微剧透）

1. 向前走，找陆伯（中央 520,440）
2. 沿北路向东，采青穗草（东北 1260,350）
3. 返回沈青药铺（西北 330,330）交药
4. 再和沈青交谈可邀其同行
5. 到东南旧渡口（1260,740）挑战蒲横
6. 回陆伯处交证据，选择「秉公」或「守望」及一个修行方向
7. 章节结束后可切磋、购买装备、调整阵型
8. 村东古道（1480,560）通往废闸，任选调查顺序，集齐两份线索后挑战闸首
9. 废闸东北（1450,250）进入霜桥驿，调查纪小砚和旧桥碑文，按线索解开印台
10. 击败韩砚后回温行舟处选择原账归处；采集木料可帮唐栖修通南桥
11. 霜桥东北古道通往雾竹坡：读雨尺与石盂 → 取得巡哨许可 → 拓叠石刻度 → 在守令使回息窗口出招 → 回秦禾处决定先疏水或先警船

12. 废闸完成且沈青已结伴后，回青苇药铺选「药箱之外」：船工近况 → 旧仓药棚 → 回药铺商议 → 村中告示。调查不扣物品，唐栖仍可留在当前队伍

无名碑（900,820）与药铺均可免费恢复；不要求磨钱或付费。战败不删除任务和物品。

## 结构

- `scripts/main.gd`：界面、剧情与流程
- `scripts/game_state.gd`：可独立测试的存档、成长与战斗规则
- `scripts/world.gd`：原创场景绘制、探索和碰撞
- `scripts/battle_art.gd`：战斗场景和角色表现
- `scripts/martial_catalog.gd`：武学数据定义
- `scripts/map_chart.gd`：五区域的只读地图概览
- `scripts/frostbridge_region.gd`、`frostbridge_story.gd`、`chapter_rules.gd`：霜桥地图、独立剧情控制与任务规则
- `scripts/item_catalog.gd`、`economy_rules.gd`、`workshop_ui.gd`：材料/配方数据、原子交易和工艺界面
- `assets/generated/`：生成背景与来源说明
- `assets/fonts/`：Noto Sans SC，许可证随附
- `tests/`：逻辑及跨场景回归测试

后续计划与验收标准见 `ROADMAP.md`。工程无需任何密钥、账号或联网请求。
