# Hero · 渡灯录

一款持续开发中的原创中文单机武侠 RPG，使用 **Godot 4.6**。离线运行、无账号、无服务器依赖，进度保存在本机。

当前内容包括可完整游玩的「青苇渡·渡口失灯」开篇和「废闸疑云」分支行纪，**不是已达到商业游戏体量的成品**。世界、故事、人物、界面、程序绘制地图与音乐均为本项目原创；背景图为独立生成素材。仅借鉴武侠 RPG 的一般玩法类型，没有复制《烟雨江湖》的文本、地图或素材。

## 运行

1. 安装 Godot 4.6.x（已在 4.6.3 验证）
2. 用 Godot 项目管理器导入本目录的 `project.godot`
3. 按 F6/F5 前请确保打开 `scenes/main.tscn`；**F5 运行整个项目**
4. 在「渡灯录」首页选择「踏入江湖」；已有本地存档时可选「续写前缘」

命令行：

```sh
godot --path .
```

目前交付为 Godot 源码工程；尚未制作并验证 Windows/macOS/Linux 独立发行包。未在真实 Windows/macOS 硬件做兼容性验收。

## 可玩的内容

- 1600×1050 原创青苇渡村落、碰撞、镜头跟随、河岸、双栈桥与动态草木/灯火
- 守灯人陆伯、药师沈青、河帮执事蒲横及采集、告示、古碑交互
- 完整任务链：接取委托 → 采草 → 送药取证 → 渡口交锋 → 证据归属抉择 → 门派荐帖
- 回合战斗：普攻蓄气、绝招真气消耗/冷却、守势、药品、敌人意图提示、撤退及败北恢复
- 沈青入队，跟随角色；并肩阵型助攻，护后阵型减伤
- 第二张废闸地图、救人/追账顺序分支、证言与账页收集、巡哨和附带破绽状态的首领
- 修为升级、铜钱、回春散购买/消耗、青钢剑购买/装备、三种门派被动加成
- 任务节点自动存档、手动存读档、完整存档校验、损坏存档保护与不安全坐标恢复
- 三种门派专属招式与熟练度阶位，可在 K 武学界面切换
- M 舆图显示实际区域、当前位置与任务目标
- 原创合成拨弦音乐、音效、独立生成的水墨渡口标题背景

## 开篇路线（含轻微剧透）

1. 向前走，找陆伯（中央 520,440）
2. 沿北路向东，采青穗草（东北 1260,350）
3. 返回沈青药铺（西北 330,330）交药
4. 再和沈青交谈可邀其同行
5. 到东南旧渡口（1260,740）挑战蒲横
6. 回陆伯处交证据，选择「秉公」或「守望」及一个修行方向
7. 章节结束后可切磋、购买装备、调整阵型
8. 村东古道（1480,560）通往废闸，任选调查顺序，集齐两份线索后挑战闸首

无名碑（900,820）与药铺均可免费恢复；不要求磨钱或付费。战败不删除任务和物品。

## 存档

Godot `user://hero_save.json`，版本 1 JSON，先写临时文件再替换。无云同步。不要分享个人存档，除非需要排错。正常版本兼容原始字段完整的旧存档，新加入的同伴/装备字段具有默认值。

## 结构

- `scripts/main.gd`：界面、剧情与流程
- `scripts/game_state.gd`：可独立测试的存档、成长与战斗规则
- `scripts/world.gd`：原创场景绘制、探索和碰撞
- `scripts/battle_art.gd`：战斗场景和角色表现
- `scripts/martial_catalog.gd`：武学数据定义
- `scripts/map_chart.gd`：两区域的只读地图概览
- `assets/generated/`：生成背景与来源说明
- `assets/fonts/`：Noto Sans SC，许可证随附
- `tests/`：逻辑及跨场景回归测试

后续计划与验收标准见 `ROADMAP.md`。工程无需任何密钥、账号或联网请求。
