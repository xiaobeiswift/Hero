# Hero painted village cast: art provenance

Created 2026-10-01 for Hero · 渡灯录. Original character artwork was produced using OpenAI's built-in image-generation tool, followed by deterministic Blender orthographic textured-card rendering for game-ready dimensions and alignment.

## Source references and generation

References were only existing original Hero project art:

- Accepted painted traveler source: `Hero-staging/visual-upgrade/painted-traveler-rig/source/painted_pose_reference.png`, used for painted material style, adult body proportions and elevated RPG camera
- Original four-character portrait atlas: `Hero-staging/portraits/hero-character-portraits-atlas.png`, used for Shen Qing's upper-right portrait identity, ivory/sage palette, scarf, hairstyle and medicine-satchel design

Four separate built-in image-generation calls made Lu Bo, Shen Qing's four-direction turnaround, Pu Heng and Cen Yuan. A fifth targeted image-generation edit corrected the right-facing Shen satchel to the far anatomical left side. All five outputs are preserved unmodified under `source/` in the authoring workspace; all are 1254 × 1254 RGBA PNG. Selected Shen source is `shen_painted_source_v2.png`, not v1.

The authoring record is retained as source/generation_record.json; the exact prompt text is also reproduced below for this runtime publication. No reference artwork from another game, named artist imitation, purchased asset, external account or paid service was used. The source images contain actual transparency; no checkerboard is baked into the image.

- 沈青 / Shen Qing: adult woman healer, matching existing portrait, ivory/sage robe, jade-sage scarf, tan-brown left-hip medicine satchel

- 岑远 / Cen Yuan: dignified adult martial instructor, muted blue-grey layered robe, composed topknot/goatee and bamboo booklet

## Processing and honest limits

Blender uses the unchanged source PNGs as transparent emission textures on flat cards. It normalizes each full-body pose to a fixed 256 × 256 cell and common `(128,241)` foot projection, then packs the rendered pixels. The source images are not repainted or programmatically recolored. The editable `.blend`, reproducible renderer and source calibration are included.

The artwork provides four village idle sprites and four cardinal idle Shen poses (seven unique sprites). It provides no walk cycle. Camera, apparel and side-specific satchel continuity were visually checked. Cell borders and packed-image equivalence were checked numerically. Tiny generated low-alpha color noise may be visible in viewers that exaggerate nearly transparent RGB, but is effectively absent when composited normally; the supplied asset QA board demonstrates composited appearance. Runtime outer four-pixel borders are completely transparent.

The original traveler appears in the QA contact sheet only as a comparison reference; it is not replaced or redistributed as a new cast sprite. The board is not a game capture.


## Initial runtime publication scope

The initial game commit includes the two rendered atlases and Godot helper. The unchanged source images, editable Blender scene and rendering tools are retained in the authoring workspace; they are not all bundled in this runtime/source increment. Only the four main Qingwei NPC idle poses are integrated here. Shen directional artwork is included as preparation, not described as a walking cycle. Her moving follower remains on the existing articulated renderer until a proper painted walk is validated. Generic villagers, other-region NPCs and combat figures are not replaced by this pack.
